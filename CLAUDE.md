# Contexto do cliente

Este repositório contém somente a entrega compartilhável do projeto SV Digital. O estado atual é a Fase 1: fundação segura em Supabase, modelo comercial/importação e painel inicial.

O canal de atendimento previsto é WhatsApp Cloud API com agente de IA supervisionado. Casos fora da política, baixa confiança, pedido de preço/condição não configurada e solicitação explícita devem ser encaminhados a uma pessoa.
